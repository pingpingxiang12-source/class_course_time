# 班级课表统计网站
> 项目简介：校内课表批量处理工具，支持导入本校PDF格式课表，自动解析并完成课表统计，可直接下载导出统计文件。无登录功能，**不保存上传的文件，无历史记录查询**。

## ✨ 功能特性
- 批量导入本校PDF课表文件
- 自动解析PDF内课程信息，汇总全班课表
- 自动统计全班共同空闲时间段
- 📥 导出统计结果为Excel表格，WPS/Excel直接打开
- 响应式页面，电脑/手机均可访问

> ⚠️ 重要说明：本网站为纯工具站点，**无账号登录功能，不会在服务器存储上传的PDF文件，不提供历史文件查询**，文件仅在浏览器临时处理。

## 🛠️ 技术栈
- 前端：Vue3 + Vite + SheetJS(xlsx) + PDF解析库
- 后端：FastAPI（Python）
- 部署：Vercel / 服务器
